# 「知微学习助手」Demo Day 演示与录屏脚本（约 2 分 40 秒）

## 0:00 – 0:25｜开场与痛点破题
- **画面**：打开新版项目方案 PPT 第 1、4 页与 GitHub 项目主页（`https://qiontoo.github.io/zhiwei-learning-copilot/`），随后切至 EPAI「知微学习助手」配置页（展示知识库、术语库、数据库、`zhiwei-pedagogy` Skill、`EdgeOne Pages MCP`、`当前时间`、`长期记忆`与`内容安全审核`）。
- **旁白参考**：
  > 大家好，我带来的是基于 EPAI 平台搭建的「知微学习助手」。很多同学在备考时都会遇到“只刷题不诊断、只看答案不理解、学完即忘”三大痛点。通用大模型习惯直接剧透答案，反而掩盖了前置知识漏洞。知微取意“见微知著”，把课程拆解为原子级微概念，打造“微诊断 → 费曼追问 → 错因归因 → 遗忘曲线调度 → 一键生成公网交互复习网页”的完整闭环。

## 0:25 – 1:05｜场景 A：知识库精准召回 + 微诊断前置回溯
- **画面**：在 EPAI「预览与调试」中输入知识库实测指令并展开处理过程。
- **重点展示**：
  1. 展示经过 **RRF 倒数排名融合 + 0.2 阈值调优** 后的 **`ZhiWei_课程知识库`** 召回 10 条片段（匹配度 `0.00 ~ 0.95`），且智能体主动识别出记录表与卡片间的编号偏差；
  2. 结合 **`知微_核心术语库`** 与 **`ZhiWei_学习记录表`**（ML-03 掌握度 40，错因「前置缺失」），智能体不直接甩答案，而是追问链式法则连乘与残差通路，并在文末输出 **「📊 知微学习状态卡」**。

## 1:05 – 1:40｜场景 B：费曼 3 轮追问检验
- **画面**：输入带故意漏洞的复述：*“我想用费曼学习法检验一下自注意力为什么要除以 sqrt(d_k)，是不是为了让输出向量模长为 1，避免数值溢出？”*
- **重点展示**：智能体精准识别出“输出模长为 1”这一常见误区，肯定合理直觉的同时引导思考 **`QK^T` 方差与 softmax 饱和区**，不剧透完整结论并给出状态卡更新建议。
